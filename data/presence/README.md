# Photos for the component presence check (see planner.md)

Read **HOW_TO_ADD_PHOTOS.txt** in this folder: folder structure, the `missing.txt` format, the 86 part names, and the photo rules.
`missing_example.txt` is a template to copy into a removal board's folder.

Short version: whole-board phone photos, **not cropped** (background around the board is fine and needed), one folder per
physical board; a board with missing parts gets `<board>_missing.txt` (e.g. `R01_missing.txt`: `Q9, R12`) next to its photos.
